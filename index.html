sampro — local audio for Chrome

Privacy policy effective date: 27 October 2026.

Record authorized audio sources, organize a local library, preview EQ and effects, select audio and export WAV. sampro 2.3.3 keeps originals on your device and provides no active cloud backup service.

Use the guide for capture permissions, editing and safe updates. Interface language of the current extension is English; these information pages are currently available in English only.

The new logo will be designed later. The product name is displayed as text for now. This website repository contains information pages only; extension source code is not included.

No extension download or Chrome Web Store listing is linked here.
