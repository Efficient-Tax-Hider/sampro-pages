Source unavailable

Invoke the toolbar on the source tab, authorize it and select it before recording. Chrome-internal pages and protected content cannot be bypassed.

No microphone or system audio

Check Chrome/Windows permissions and the selected device or share surface. The system picker must offer an audio track. Stop active recording before adding sources.

Effects or export

Check bypass, EQ/gain, Processed preview and Export processed copy. Original recordings do not include monitoring effects. For oversized or undecodable sources, download the original for another editor.

Storage failure or missing library

Keep Chrome open and use Retry archive for unsaved chunks. Do not uninstall or clear the profile to fix an archive failure. After an update, use the same Chrome profile and installed extension entry; another path can create another ID and a different library.

Contact

Include sampro and Chrome versions, OS, source type, reproduction steps, expected behavior and the error text. Diagnostic export is optional: review it and remove sensitive context before sharing. Do not send private recordings or temporary media-access URLs unless necessary. This page has no form and sends nothing automatically.
