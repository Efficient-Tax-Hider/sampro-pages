Guide and safe updates

Privacy policy effective date: 27 October 2026.

First local installation

  1. Open chrome://extensions and enable Developer mode.
  2. Select Load unpacked and choose the existing sampro-Chrome-v2.3.3 extension folder. These website files are not an extension.
  3. Open a regular media website and invoke sampro from the Chrome toolbar.

Keep existing recordings when updating

Download important originals, stop and save active recordings, and close old Studio windows. Replace extension files in the same installed directory and Reload the same extension entry. Do not uninstall, clear extension data or switch directories as an update procedure. Check the existing library and download a saved original afterwards. Full library backup/restore is not included.

Record and edit

Invoke the toolbar on each source tab you want to authorize. Select approved sources in Sources; request microphone or system audio through Chrome when needed. Enter a name and optional tags, press Record, then Pause/Resume or Stop. Each source is saved separately. Closing the panel does not stop capture. Stop before adding new sources.

For microphone-only capture, authorize the microphone, enable Record Microphone and Record Any Tab, and leave tab sources unselected. System audio needs an authorized selected system source that actually supplies an audio track.

Open a saved track in Studio. IN/OUT, looping, zoom and Auto-Trim change the selection, not original bytes. Enable Processed preview to audition effects and Export processed copy to include them in WAV. Original download preserves the stored audio.

Limits

Protected media, browser-internal pages and inaccessible frames may not work. System audio depends on Chrome, Windows and the chosen share surface. Granular pitch does not preserve formants. The limiter is not a true-peak guarantee. Long-source processing can be refused; native decoder memory is not fully controllable. A short selection does not make a complete long source safe to decode. Download the original when processing is unavailable.

No Drive or cloud backup service is active. Real Realtek microphone capture and an independent native system-audio diagnostic were tested on 25 October 2026; subjective acoustic listening remains untested. The production SYSTEM path was fixed and verified through native capture. Keep its system-audio source window open while sharing; closing it stops that source and saves its recording. The recorder panel can close independently.
